# Virtual Launch Lab

가상 로켓 착륙 실험실입니다. **물리는 X–Y 평면의 2D 운동**으로 계산하며, Three.js의 3D 장면은 기체와 궤적을 시각적으로 표현합니다. 공중에서 시작해 추력과 짐벌을 조절합니다. 수동 조종과 저장소에 포함된 PPO 모델의 브라우저 추론을 지원합니다. 배포 버전 18에서 무작위 하강 50회 중 50회 착륙을 관측했습니다.

[웹 시뮬레이터](https://virtual-launch-lab-woojun.aa01066365388.chatgpt.site) · [개발 파이프라인 한눈에 보기](docs/development-pipeline.md) · [이전 실험 기록](docs/legacy-experiments.md)

## 실행 (Windows / VS Code)

Node.js 22 LTS 이상을 설치하고 저장소를 업데이트한 뒤 `start-simulator.cmd` 또는 `open-web.cmd`를 실행합니다. 터미널에서도 실행할 수 있습니다.

```sh
npm ci
npm run dev -- --open
```

터미널에 표시되는 localhost 주소로 접속하세요. HTML 파일 더블클릭은 지원하지 않습니다.

## 조작

먼저 **시뮬레이션 시작**을 누릅니다.

| 키 / 버튼 | 동작 |
|---|---|
| Space 또는 ↑ | 누르는 동안 엔진 점화, 떼면 컷오프 |
| ↑ / ↓ | 점화 출력 설정을 40~100%로 조정 |
| ← / → | 짐벌 조향, 떼면 중앙으로 복귀 |
| M / AI·MANUAL 버튼 | 제어 모드 전환 (기체 상태·궤적 유지) |
| R / RESET | 새로운 하강 조건으로 초기화 |
| 일시정지 | 물리와 연기를 일시정지 |
| 드래그 / 휠 | 카메라 회전 / 확대 |

화면 버튼에서 키보드 포커스가 남아 있다면 3D 화면을 클릭하세요. 포커스 이탈·탭 전환·리셋 때 눌린 키를 해제합니다. 모델 로드 실패 시 기존 모드를 유지하고 일시정지합니다. AI 기능을 수동 정책으로 대체하지 않습니다.

## 표시와 한계

- 파란 실선: 물리 스텝마다 기록하는 **실제 표시 노즐 출구** 궤적. 최근 1,200개 포인트를 유지합니다.
- 링과 점선: **추력·항력 제외, 일정 중력**의 탄도 예상 낙하지점. 점선 자체는 탄도 곡선이 아닙니다.
- 초록 ≤2.5m / 주황 ≤12m / 빨강 >12m: 예상 수평 오차 구간. 초록은 착륙 성공 판정이 아닙니다.
- 연기: 900개 고정 파티클 풀과 Canvas 생성 텍스처. 감속·상승을 흉내 낸 시각 효과이며 CFD가 아닙니다.
- 격자 핀·전개식 다리는 시각 효과입니다. 공력·다리 접촉·파손 모델은 연결되어 있지 않습니다.
- 현재 새 앱에는 발사·단분리·궤도 운동·전체 추진체 회수 학습이 없습니다. 브라우저는 학습된 PPO의 **추론**만 수행합니다.

## 물리 및 학습

`shared/physics_config.json`을 Python과 JS가 함께 사용합니다. 상태는 `[x,y,vx,vy,theta,omega,fuel]`, Y-up 좌표계이며 0.05초 명시적 오일러 적분을 사용합니다. 위치·각도는 이전 스텝의 속도로 적분합니다.

수동 조종은 컷오프 0%를 허용하므로 PPO의 행동 범위(40~100%)와 다릅니다. 힘·토크·연료·접지 판정 수식은 공유합니다. 600스텝(30초)에서 시간 제한으로 종료하며, 이 경우 추락으로 표시하지 않습니다. 실제 기체에 대해 검증된 모델은 아닙니다.

```sh
python -m pip install -r rl-pipeline/requirements.txt
python rl-pipeline/train_ppo.py
python rl-pipeline/export_onnx.py
```

학습은 500,000 timesteps를 요청하며 SB3의 완전한 rollout 단위로 약 501,760스텝까지 진행됩니다. 결과는 `rl-pipeline/models/`에 저장됩니다. 새 내보내기 파일은 `rl-pipeline/models/export/`에 저장됩니다. 배포 모델의 원본 학습 체크포인트는 저장소에 포함되어 있지 않습니다.

### 배포 모델 평가 재현

`python rl-pipeline/evaluate_release.py`는 현재 릴리스 파일을 CPU에서 읽고, 시드 0–99로 조건당 100회 평가한 뒤 결과를 콘솔과 `docs/evaluation-report.md`에 기록합니다.

| 조건 | 성공률 | out_of_bounds | crash | timeout | 접지 표본 |
|---|---:|---:|---:|---:|---:|
| 기본 조건 | 98/100 | 0 | 2 | 0 | 100 |
| 초기 조건 범위 1.5배 | 84/100 | 2 | 14 | 0 | 98 |
| 측풍 −5 m/s | 1/100 | 0 | 99 | 0 | 100 |
| 측풍 +5 m/s | 0/100 | 0 | 100 | 0 | 100 |

웹 버전 18의 기존 무작위 50회 평가와 이 고정 시드 평가는 초기 조건이 다릅니다. 보고서에서 에피소드별 초기 상태, 실제 접지 표본의 오차와 성공 기준 대비 여유율을 확인할 수 있습니다. [평가 보고서](docs/evaluation-report.md) · [배포 파일 체크섬](public/models/README.md)

## 검증과 빌드

```sh
npm test
npm run build
npm run preview
```

`npm test`는 새 웹 모듈 및 기존 CJS 테스트를 실행합니다. Python 검증은 `python -m unittest discover -s tests -p "test_*.py"`로 별도 실행합니다(공식 Python 환경과 Node.js 시뮬레이션을 대조하며 Node.js도 필요합니다).

브라우저 주사율과 무관하게 물리 dt를 고정하며, ONNX 추론은 한 번에 한 스텝만 진행합니다. 느린 장치에서는 실제 시간보다 재생이 느려질 수 있습니다. Python/JS/ONNX의 비트 단위 일치나 학습 성능을 보장하지 않습니다.

## HUD 디자인 및 연속 실행 업데이트

Space Grotesk / JetBrains Mono, 글래스 패널, 시안·앰버 게이지, 다중 패드 링, 그라데이션 화염과 지면 연기 효과를 사용합니다. 외부 폰트가 차단되면 시스템 폰트로 표시합니다.

- 통계는 완료된 에피소드만 한 번 집계하며 수동/AI를 합친 전체 결과입니다. 시간 제한도 시도 횟수에 포함됩니다. `AVG FINAL X`는 종료 시 수평 오차로, 접지하지 않은 실행도 포함합니다.
- AUTO-BENCHMARK는 로드된 PPO 모드에서만 켤 수 있으며, 첫 실행은 시작 버튼으로 시작합니다. 재생 속도에 따른 대기 시간 후 다음 무작위 드롭을 자동 실행합니다. 학습이나 정책 최적화를 수행하지 않습니다.
- 수동 리셋·모드 변경·오류·토글 해제 시 재시작 타이머를 취소합니다. 숨겨진 탭에서는 다음 실행을 시작하지 않습니다.
- 측풍 슬라이더의 기본값은 0 m/s입니다. 가상 외란은 `수평 가속도 = 0.1 × 풍속`으로 더합니다. 슬라이더 변경은 다음 물리 스텝부터 반영되며 자동 반복에도 같은 설정이 적용됩니다.
- ZEM/ZEV·호버슬램 폴백 및 Python 보상/학습 변경은 포함되지 않았습니다. 모델이 없으면 AI 모드를 실행할 수 없습니다.

이번 디자인 업데이트는 요청에 따라 테스트·학습을 실행하지 않았으며, 배포용 빌드만 수행합니다.
