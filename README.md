# Launch Lab v0.3 — 점화·단분리·낙하

[웹 실험실](https://virtual-launch-lab-woojun.aa01066365388.chatgpt.site)

2026-11-18. 특정 실제 로켓 제원과 무관한 교육용 질점 실험입니다. 물리식에 기반한 수직 운동과 3D 표현을 구분합니다.

## 사용

압축을 모두 풀고 `open-web.cmd` 또는 `dist/index.html`을 Chrome/Edge에서 엽니다. 서버와 Python 설치 없이 웹 실험을 실행할 수 있습니다. WebGL 그래픽 가속이 필요합니다.

점화 시퀀스 시작 → 3초 카운트다운 → 점화·상승 → 시뮬레이션 시작 8초에 연소 종료·단분리 → 두 물체의 관성 상승 → 낙하 → 둘 다 지면 도달 시 종료.

추진체 추적 / 상단 추적 / 두 기체 / 발사대 / 상부 카메라, 탱크 단면, 흔적, 화염, 배속, 일시정지, CSV를 지원합니다. 고도 그래프는 두 물체를 함께 표시합니다. 단분리 이후 수치 카드와 힘 그래프는 추진체 기준입니다. 초기화하면 다시 결합됩니다.

**기본 표시의 좌우 벌어짐과 회전은 설명용 연출입니다.** 분리 순간 좌우 2 m로 뛰던 이전 표시를 없애고, 시작 위치·속도가 이어지는 부드러운 표시 전환으로 바꿨습니다. `분리·회전 연출`을 끄면 수직 질점 좌표를 그대로 표시하며 회전하지 않습니다. 연출은 계산 결과와 CSV에 영향을 주지 않습니다. 상단 고도는 상단 부품의 바닥 기준으로, 결합 상태에서 추진체 기준보다 1.5 m 높습니다. 3D 형상은 설명용입니다.

## 식과 가정

수직 위를 +로 두고 `dh/dt=v`, `dv/dt=(T−mg−D)/m`, `D=0.5 ρ Cd A v|v|`를 사용합니다. `v<0`이면 D도 음수이므로 항력은 위쪽입니다.

점화 전/상승: 건조질량 5 kg, 연료 2 kg, 최대 추력 100 N, 최대 연료 소모 0.12 kg/s, 0.8초 점화 램프. g=9.81 m/s², ρ=1.225 kg/m³, Cd=0.45, A=0.035 m². 모든 값은 교육용 합성값입니다.

분리: 시작 후 8초라는 고정 시나리오 이벤트입니다. 최적 분리 시점이 아닙니다. 상단 질량 2 kg, 추진체 질량은 분리 직전 전체 질량에서 2 kg을 뺀 값으로, 남은 연료를 포함합니다. 분리 충격은 0으로 가정해 두 물체는 직전 수직 속도를 그대로 이어받습니다. 따라서 이상적 분리 순간 질량과 수직 운동량이 보존됩니다. 물리적 분리장치, 동체 간 접촉·공력 간섭은 계산하지 않습니다.

분리 후: **두 물체 모두 추력 0**. 상단 A=0.01 m², 추진체 A=0.035 m², Cd=0.45의 독립 낙하 질점입니다. 실제 공력 자료로 식별한 값이 아닙니다. 상단도 최고점 이후 떨어집니다. 추진체 잔여 연료는 분리 후 소모하지 않습니다. 위치·속도를 explicit midpoint 방법, Δt≤0.005 s로 적분합니다. 지면에 도달하면 높이와 속도를 0으로 고정하며 충돌·파괴 해석은 하지 않습니다. 접촉 시점에는 최대 한 스텝의 오차가 있습니다.

물리 솔버의 회전·자세·그리드핀·횡풍·연소화학·재점화·역추진·회수·강화학습은 미구현입니다. 실기 비행/회수 성능을 예측하는 모델이 아닙니다. 화염과 배기는 시각 효과입니다.

## 코드·검증

- `dist/physics.js`: 기존 기본 발사 모델
- `dist/staging.js`: 교육용 분리 이벤트와 두 물체 낙하
- `dist/scene.js`, `dist/app.js`: 3D와 실험 UI
- `tests/physics.cjs`: 기본 물리 검사 11개
- `tests/staging.cjs`: 분리 순간 보존, 지면 도달, 항력 부호, 시간분할/초기화 4개
- `tests/geometry.cjs`, `tests/ui.cjs`: 기하 및 모의 DOM
- `tests/reference.py`: 독립 SciPy 비교 (Python과 SciPy 필요)

```
node tests/physics.cjs
node tests/staging.cjs
node tests/geometry.cjs
node tests/ui.cjs
python tests/reference.py
```

SciPy 1.17.0 DOP853과 분리 후 2초 구간을 비교했습니다. 상단/추진체 높이 차이는 각각 약 1.85e-6 / 2.76e-6 m였습니다. 이는 **동일한 이상화 ODE에 대한 수치 검산**이며 실제 비행 오차가 아닙니다. 전체 비행·충돌 이벤트를 SciPy와 교차검증한 것도 아닙니다.

이번 환경에는 브라우저 제어가 없어 실제 WebGL 화면, GPU별 성능, 터치·다운로드를 직접 검증하지 못했습니다.

CSV model=`educational_split_bodies_v02`. time(s), height/upperHeight/boosterHeight(m), velocity/upperVelocity/boosterVelocity(m/s), acceleration(m/s²), mass/fuel/upperMass/boosterMass(kg), thrust/weight/drag(N). 분리 전 mass는 전체, 분리 후 mass는 추진체이며 separated로 구분합니다. 상단 질량은 분리 전 CSV에서 0(별도 활성 물체가 아님)으로 기록됩니다. upperGrounded/boosterGrounded는 지면 도달 상태입니다.

## v0.3 영상 참고와 표시 수정

참고: [NASA Apollo 4 실제 탑재 카메라 영상 / Wikimedia Commons 공개본](https://commons.wikimedia.org/wiki/File:Separation_of_Rocket_Stages_During_Apollo_4.webm). NASA 촬영, 1967-11-09. 전체 영상의 12초 간격 프레임과 파일 내 16~38초 구간의 2초 간격 프레임을 직접 확인했습니다. 해당 파일의 편집 시간이며 비행 경과 시간으로 간주하지 않습니다. 상단 카메라 시점에서 하단/연결 구조가 연속적으로 멀어지는 모습을 확인했습니다. 이 영상은 Falcon 9이나 현대 회수 비행 영상이 아닙니다. 영상에서 분리 힘·각속도·공력계수를 추정하지 않았습니다.

ESA `First-stage separation` 자료도 확인했으나 해당 자료는 GOCE mission animations에 속한 애니메이션이므로 실제 촬영 근거로 사용하지 않았습니다.

변경 사항:
- 분리 순간의 강제 좌우 점프 제거. 설명용 간격은 0에서 부드럽게 증가합니다.
- 설명용 회전은 모델의 표시 중심을 기준으로 수행합니다. 실제 질량중심·관성·공력 토크에서 구한 회전이 아닙니다. 지면 도달 이후 표시 회전은 정지합니다.
- 지면 기준 카메라 추가, 추적 카메라 이동 완화, 5 m 간격 높이 눈금 추가. 고정 자세·카메라 때문에 낙하가 안 보이는 문제를 완화합니다.
- 경로선은 물리 모델의 수직 질점 경로를 표시합니다. 연출 모드의 옆으로 벌어진 형상과 경로선은 의도적으로 다릅니다.
- 연출 모드에서 회전 형상이 지면 아래로 내려가는 경우 표시만 위로 보정합니다. 접촉 강체역학은 아닙니다.

`dist/presentation.js`는 물리 계산과 분리된 표시 함수입니다. 새 `tests/presentation.cjs`는 순간이동 방지·연출 해제·접촉 이후 정지·초기화를 확인하고, 형상 검사에서 실제 Three.js 변환과 카메라 좌표도 확인합니다. 기본 물리 및 SciPy 교차검산 결과는 유지됩니다.

현재 개선은 **표시 논리 수정이며, 실제 단분리와 3차원 낙하 역학을 완성한 것은 아닙니다.** 수직 운동 제한과 분리 충격·토크 생략은 남아 있습니다. 실제 브라우저 렌더링은 직접 검증하지 못했습니다.
