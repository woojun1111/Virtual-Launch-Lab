# Landing Lab 웹 실행 (2026-11-22)

현재 새 진입점은 루트 `index.html` + `src/main.js`입니다. 이전 `dist/index.html`은 기존 발사 실험이며 새 UI가 아닙니다.

## Windows / VS Code

1. Node.js 22 LTS 이상 설치 후 저장소 최신 내용을 받습니다 (`git pull`).
2. `start-simulator.cmd`를 실행하거나 터미널에서 아래 명령을 실행합니다.

```sh
npm ci
npm run dev -- --open
```

브라우저에 표시된 localhost 주소로 접속합니다. HTML 파일 더블클릭으로는 실행되지 않습니다.

- 기본 **수동 실험**: 시작/일시정지, 추력·짐벌 슬라이더, 리셋 버튼 또는 R 키.
- **PPO 모델 실행**: 학습·내보내기한 ONNX 모델을 사용합니다. 모델이 없으면 오류와 수동 모드 링크를 표시합니다. 임의 정책으로 대체하지 않습니다.
- 카메라: 드래그 회전, 휠 확대. HUD: 고도, 수평 위치, 속도, 피치, 짐벌, 연료, 추력, 종료 결과.
- 현재 범위는 공중에서 시작하는 2D 착륙 환경을 3D로 표시하는 것입니다. 발사·단분리·궤도·그리드핀 공력·실시간 PPO 학습은 포함하지 않습니다. 그리드 핀과 다리 전개는 시각 효과입니다.

## 궤적 · 탄도 예측 · 지면 연기

- 파란 궤적은 물리 스텝마다 노즐 출구의 월드 좌표를 기록합니다. 최대 최근 1,200개(0.05초 기준 약 60초)를 유지하며, 현재 환경은 최대 30초에 종료됩니다.
- 링은 현재 상태에서 추력·항력을 제외하고 일정 중력만 적용한 예상 낙하지점입니다. 점선은 그 지점을 연결하는 안내선이며 탄도 곡선 자체가 아닙니다.
- 초록(≤2.5m), 주황(≤12m), 빨강(>12m)은 예상 수평 오차 범위입니다. 초록이라도 착륙 속도·자세 조건을 충족하지 않으면 성공하지 못합니다.
- 연기는 실제 추력이 있고 노즐 배기 방향이 지면을 향할 때만 발생합니다. 600개 고정 풀, Canvas 생성 텍스처, 입자별 크기·투명도 셰이더를 사용합니다. 감속과 부력을 흉내 낸 시각 효과이며 CFD 해석은 아닙니다.
- 일시정지 시 연기를 멈추고, 리셋 시 궤적과 연기를 지웁니다. 종료 후 궤적은 남고 예측 링은 숨깁니다.

## 식과 가정

수직 위를 +로 두고 `dh/dt=v`, `dv/dt=(T−mg−D)/m`, `D=0.5 ρ Cd A v|v|`를 사용합니다. `v<0`이면 D도 음수이므로 항력은 위쪽입니다.

점화 전/상승: 건조질량 5 kg, 연료 2 kg, 최대 추력 100 N, 최대 연료 소모 0.12 kg/s, 0.8초 점화 램프. g=9.81 m/s², ρ=1.225 kg/m³, Cd=0.45, A=0.035 m². 모든 값은 교육용 합성값입니다.

분리: 시작 후 8초라는 고정 시나리오 이벤트입니다. 최적 분리 시점이 아닙니다. 상단 질량 2 kg, 추진체 질량은 분리 직전 전체 질량에서 2 kg을 뺀 값으로, 남은 연료를 포함합니다. 분리 충격은 0으로 가정해 두 물체는 직전 수직 속도를 그대로 이어받습니다. 따라서 이상적 분리 순간 질량과 수직 운동량이 보존됩니다. 물리적 분리장치, 동체 간 접촉·공력 간섭은 계산하지 않습니다.

분리 후: **두 물체 모두 추력 0**. 상단 A=0.01 m², 추진체 A=0.035 m², Cd=0.45의 독립 낙하 질점입니다. 실제 공력 자료로 식별한 값이 아닙니다. 상단도 최고점 이후 떨어집니다. 추진체 잔여 연료는 분리 후 소모하지 않습니다. 위치·속도를 explicit midpoint 방법, Δt≤0.005 s로 적분합니다. 지면에 도달하면 높이와 속도를 0으로 고정하며 충돌·파괴 해석은 하지 않습니다. 접촉을 검출한 스텝의 양 끝 높이를 선형보간해 시각과 충돌 직전 속도를 추정합니다. 비선형 운동의 정확한 근 탐색은 아니므로 보간 오차가 남습니다.

물리 솔버의 회전·자세·그리드핀·횡풍·연소화학·재점화·역추진·회수·강화학습은 미구현입니다. 실기 비행/회수 성능을 예측하는 모델이 아닙니다. 화염과 배기는 시각 효과입니다.

## v0.3.1 — 이륙 실패 종료 및 충돌 기록 보존

사용자 코드 리뷰를 바탕으로 이륙 실패 정지 버그를 재현했습니다. 수정 전 0 추력 시험은 2초 타임아웃으로 종료됐습니다. 분리 예정 시각에 아직 이륙하지 않은 경우 더 이상 epsilon 스텝을 반복하지 않고 `state=complete`, `terminationReason=no_liftoff`로 종료합니다. 정상 분리 시나리오와는 별도로 기록합니다.

지면 통과 스텝에서 이전 높이/속도와 새 높이/속도를 보존하고, 높이 0의 선형보간 비율로 impactTime과 impactVelocity를 계산합니다. 이후 정지 상태의 속도만 0으로 설정합니다. 이벤트 객체·화면·CSV의 `upperImpactTime`, `upperImpactVelocity`, `boosterImpactTime`, `boosterImpactVelocity`는 충돌 이후에도 유지됩니다. 단위는 시뮬레이션 시작 기준 s와 위쪽을 +로 한 m/s입니다. 충돌 전에는 null이며 CSV에서는 빈칸입니다. 두 물체의 지면 도달 완료는 `terminationReason=ground_contact`입니다. 착륙 성공/실패 기준은 도입하지 않았습니다.

새 `tests/events.cjs`는 0/약한 추력의 제한 시간 내 종료, 예정 시각 경계, 충돌 기록 보존·초기화, 단순 무항력 낙하 해석해와 보간 결과를 비교합니다. UI 검사도 최종 CSV에 음의 충돌 속도가 남는지 확인합니다.

- 분리 전후 적분법이 다른 것은 유지보수 문제지만, 그 사실만으로 수렴 실패의 원인이라고 단정할 수는 없습니다. 동일 ODE·초기값·불연속 이벤트 처리를 사용한 기준해와 비교해야 합니다. 이번에는 RK4로 통합하지 않았습니다.

## v0.4 — Recovery Arcade: 작은 게임에서 실제 Q-learning

메인 화면의 **강화학습 게임 실험실** 또는 `dist/arcade/index.html`을 엽니다.
20,000회 학습 → 정책 평가 → 발사부터 재생. 모델 JSON 저장/불러오기,
학습 이어하기, 중지, 초기화, 평가 JSON 다운로드를 지원합니다.
Windows에서도 Python 설치 없이 Chrome/Edge에서 실행됩니다.

### 범위

기존 1D 물리 실험은 보존했습니다. 새 모드는 별도의 **2D 이산 게임**이며
연속 강체역학·6DOF·PPO·실제 회수 유도 구현이 아닙니다.
곡선 상승과 상단 분리는 시간에 따른 **시각 연출**이며 학습 대상이 아닙니다.
분리 후 학습 정책의 좌표를 보간해 표시합니다. 기체 기울기도 표시 효과입니다.
상단은 연출 경로로 화면 밖으로 이동합니다. 분리 보존법칙을 검증한 모델이 아닙니다.
기존 물리 실험을 완전한 회수 시뮬레이터로 바꿨다는 의미가 아닙니다.

### 상태·규칙·평가

- 상태: 가로 격자 x, 남은 높이 h, 낙하 속도 단계 v, 감속 자원 f.
- 초기 x는 -6~6 중 균등 선택, h=18, v=1, f=8. 목표는 x=-1~1.
- 행동: 대기 / 왼쪽 한 칸 / 오른쪽 한 칸 / 감속.
- 감속은 자원 1을 쓰고 속도 단계를 1 감소(최소 1). 나머지는 1 증가(최대 3).
- 한 턴에 h가 v만큼 감소. x가 -10~10을 벗어나거나 지면 도달 시 종료.
- 가상 손상은 접촉 속도 단계에서 `min(1,((v-1)/2)^2)`로 정의합니다.
  경계 이탈 손상은 1. 재료·구조·실제 파손률에 대한 모델이 아닙니다.
- 성공: 목표 구역 안 + 접촉 + 손상 ≤0.05. 목표 밖 부드러운 착륙은 실패.
- 보상: 턴 -0.2, 목표와의 격자 거리 감소 ×0.5, 감속 사용 -0.15.
  종료 시 성공 +100, 손상 ×-100, 목표 오차 ×-10, 실패 -20.
- 모든 에피소드는 최대 18턴 안에 종료하므로 공중 대기로 보상 회피 불가.

Q-learning은 alpha=.15, gamma=.98, epsilon=max(.08,.9*exp(-episodes/12000)).
종료 상태에서는 다음 상태의 Q값을 bootstrap하지 않습니다.
이는 원문의 수렴 조건을 모두 충족하는 최적성 증명이나 심층 강화학습 구현은 아닙니다.
모델 JSON에는 Q 테이블과 누적 에피소드를 저장합니다. 불러온 뒤 난수열은
저장 seed에서 다시 시작하므로 이전 학습의 비트 단위 연속 재개는 아닙니다.

### 논문·오픈소스의 실제 적용

- [Watkins & Dayan (1992), Q-learning](https://www.gatsby.ucl.ac.uk/~dayan/papers/cjch.pdf):
  temporal-difference Q 업데이트를 독립 구현했습니다. 로켓 제어 논문이 아닙니다.
- [Gymnasium Toy Text 공식 문서](https://gymnasium.farama.org/environments/toy_text/),
  [Farama Gymnasium 공개 코드](https://github.com/Farama-Foundation/Gymnasium):
  작은 이산 상태/행동 공간 및 reset/step 환경 분리 구조를 참고했습니다.
  Gymnasium 코드 복제, 패키지 실행, Gym API 완전 호환을 주장하지 않습니다.
- 사용자 제공 vidIQ 영상 분석은 카메라·화염·성공 표시·반복 재생의 참고입니다.
  이 구현에서 원본 영상의 정책·알고리즘·물리 모델을 추출한 것은 아닙니다.
