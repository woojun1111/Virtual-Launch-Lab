# Planar rigid-body foundation

이 모듈은 기존 격자 게임과 분리된 **일정 질량 2차원 강체 검증 모듈**입니다.
학습 정책이나 웹 화면에는 아직 연결하지 않았습니다. 실제 발사체 엔진·회수
제어·가변 질량·공력·충돌 솔버·구조 손상은 포함하지 않습니다.

## 수학적 계약

상태: x,z,vx,vz,angle,omega; 매개변수: mass,inertia.
좌표는 오른쪽 x, 위쪽 z; 각도는 x축에서 z축으로 향하는 회전이 양수입니다.
`dx/dt=vx`, `dz/dt=vz`, `dv/dt=F/m`, `dangle/dt=omega`, `domega/dt=tau/I`.
SI 단위를 일관되게 입력할 수 있으나 예제 매개변수는 임의의 검증 값입니다.
중력은 자동으로 추가되지 않습니다. 필요한 외력은 load callback으로 전달합니다.

각 load의 force는 세계 좌표, point는 질량중심 기준 물체 로컬 좌표입니다.
point를 angle로 회전한 r에 대해 `tau=rx*Fz-rz*Fx`를 계산합니다.
RK4의 각 중간 상태와 시각에서 하중을 재평가합니다. step은 입력 상태를 바꾸지
않습니다. load callback은 반환값 외의 부작용 없이 작성해야 합니다.
고정 시간 간격 RK4이며 적응형 오차 제어·불연속 이벤트 탐색은 구현하지 않았습니다.

결합 해제는 충격 없이 수행합니다. 부품의 질량 가중 중심은 부모 중심과 같아야
하며 부모 관성은 평행축 정리로 계산한 합과 같아야 합니다.
각 부품 속도는 `v_parent + omega × r`로 초기화합니다. 각 부품의 초기 자세와
각속도는 부모와 같습니다. 부품 위치는 질량중심 좌표로 표시됩니다.
보존량 L은 세계 원점에 대한 궤도 각운동량과 자체 회전 각운동량의 합입니다.

`pointVelocity`는 특정 접촉 후보점의 속도만 계산합니다. 충돌을 처리하거나
속도를 0으로 만드는 함수가 아니며 충격량·손상 계산도 하지 않습니다.

## 실행

저장소 루트에서 Node.js로:

```sh
node tests/rigid2d.cjs
node experiments/rigid-release.cjs > rigid-release.csv
```

CSV 예제는 외력이 없는 두 강체의 결합을 t=1에 해제합니다. 우주선 비행이나
발사·착륙 시나리오가 아니라 보존법칙 확인용 벤치마크입니다. 충격을 가하지
않으므로 각 부품 중심의 관성 운동이 이어집니다. 겹침/접촉은 처리하지 않습니다.

## 검증 결과

- 자유 병진·자유 회전: 해석해 일치
- 일정 중심 힘과 힘 쌍에 의한 일정 토크: 해석해 일치
- 분리 선운동량 잔차: x,z 모두 0
- 분리 각운동량 잔차: 약 7.11e-15
- 분리 운동에너지 잔차: 0
- 단순 조화진동 해석해와의 상태 오차 (t=2):
  dt=.2에서 2.666e-5, .1에서 1.667e-6, .05에서 1.042e-7.
- 잘못된 질량/관성/시간 간격/부품 구성을 거부

오차 수치는 해당 합성 시험의 결과이며 일반적인 오차 상한이나 실물 검증이 아닙니다.
다음 연결 작업 전에 충돌 솔버와 이벤트 시각 처리를 별도로 검증해야 합니다.
