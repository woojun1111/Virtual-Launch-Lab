## 제공된 평가표의 해석

사용자 보고: 레벨 0, 새 시드 100개.

| 정책 | 회수 성공 | 패드 적중 | 평균 손상 지표 |
|---|---:|---:|---:|
| 무제어 | 0% | 11% | 1.00 |
| 수동 작성 유도 | 24% | 71% | 0.60 |
| 학습 정책 | 9% | 9% | 0.05 |

이 표만으로 학습 정책이 물리적으로 더 우수하거나 부드러운 착륙을 학습했다고
확정할 수 없습니다. 손상의 평균 분모, 미접촉/시간초과/경계이탈 처리,
성공 판정 정의, 정책 간 동일 초기조건 사용 여부가 필요합니다.
회수 성공률 기준으로는 보고된 학습 정책이 수동 기준선보다 낮습니다.
단일 학습 seed와 단일 체크포인트의 결과는 알고리즘 전체의 우열 근거가 아닙니다.
새 평가 seed도 새로운 상태 분포나 분포 밖 일반화 검증을 뜻하지 않습니다.

임의의 하중 임계값과 가중치로 합성한 0~1 수치는 '실제 파손률'이 아니라
'손상 대리지표'로 표기해야 합니다. 열부하/횡력/가속도/접촉의 기여와 누적 규칙,
단위, 중복 벌점 여부 및 보정 근거를 별도로 기록해야 합니다.
손상 단조성은 구현 불변량이며 실제 구조 파손 모델의 타당성 증거가 아닙니다.

## 물리적 설명에서 정정할 점

- 높은 정압 자체가 기체를 뒤집는 원인이라고 단정할 수 없습니다.
  공력 회전은 상대 유동, 동압, 자세, 압력중심과 질량중심의 관계 및
  사용한 공력계수와 좌표계에서 확인해야 합니다. 대기압과 동압을 구분합니다.
- 재상승의 원인이 피드포워드라는 설명은 원인 가설입니다.
  명령 출력, 실제 출력, 질량, 접촉 이벤트와 상태 시간열 없이 확정하지 않습니다.
- 치올콥스키 해석해 비교는 해당 가정의 진공 연소 구현 검증입니다.
  회전, 공력, 접촉, 질량중심/관성 변화나 전체 비행을 함께 검증하지 않습니다.
- RK4라는 이름만으로 정확성을 보장하지 않습니다. 중간 단계 질량 및 힘 평가,
  연료 고갈·분리·접촉 불연속 처리, 시간 간격 수렴을 따로 확인해야 합니다.
- ES는 확률적 정책 탐색 방법으로 사용할 수 있습니다. 알고리즘 이름을 PPO로
  바꾸는 것만으로 물리 오류나 지표 편향이 해결되지는 않습니다.

## 재현 자료 체크리스트

1. 코드 ZIP, 원본 출처/라이선스, 의존성 및 실행 명령.
2. 코드 commit, 환경/지표 버전, 레벨, 학습 seed와 평가 seed 목록.
3. 정책 체크포인트와 학습 설정; 평가 중 정책이 고정되는지 확인.
4. 에피소드별 종료 사유: 접촉/시간초과/경계이탈/수치오류 등.
5. 성공/패드 적중/손상 각 지표의 정의와 분모; 결측치를 0으로 채우지 않기.
6. 접촉 직전 위치·속도·각도·각속도 및 접촉 여부. 정지 후 0으로 덮어쓰지 않기.
7. 동일 초기조건에서 각 기준선 평가, 원시 결과와 집계 결과의 일치.
8. 테스트 실행 출력과 각 테스트의 실제 검증 범위.

이 검토는 평가의 정확성과 물리 검증 범위에 관한 것입니다.
착륙 유도·제어 성능 향상이나 보상/정책 최적화 변경은 적용하지 않았습니다.

## 2026-11-21 첨부 파일 확인

이전의 '파일 미제공' 상태는 해소됐습니다. rl-recovery-module.zip(44,179 bytes)을
읽기 전용으로 검사했습니다. 환경·기준선·학습·평가 소스, 테스트, 정책 및
재생 JSON, 학습 로그가 들어 있습니다. 아래는 소스/저장 데이터 검사 결과이며
모델 실행이나 환경 테스트 10개 재현 결과가 아닙니다.

- eval.js의 meanDamage는 전달된 전체 rows의 damage 합 / rows.length입니다.
  접촉 사례만의 평균이 아닙니다. 종료 사유별 집계도 출력합니다.
  100회 평가 원시 rows는 동봉되지 않았으므로 보고된 집계값 자체는 재현하지 않았습니다.
- train.js는 현재 가중치가 아니라 검증 보상 최고 가중치(bestW)를 저장하지만,
  gens는 저장 당시 반복 횟수로 기록합니다. 로그 최고 보상은 10세대 -21.09,
  정책 bestReturn은 -21.089279992292578, 저장 시점은 135입니다.
  따라서 '135세대의 현재 정책'과 '135세대까지 탐색해 선택한 정책'을 구분해야 합니다.
- 동봉 episode는 level=0, seed=500000, missed_pad입니다. 패드 오차 82.4735,
  손상 대리지표 0.129783, 접촉 수직속도 약 -2.51546로 기록돼 있습니다.
  이 한 사례를 전체 평균 0.05나 성공률 9%의 재현으로 취급하면 안 됩니다.
- 평가 스크립트는 n%5===0일 때만 프레임을 기록합니다. 초기/최종 상태가
  반드시 포함되는 구조가 아니므로 재생 프레임 끝과 최종 info를 구분해야 합니다.
- 훈련 재개는 가중치를 읽지만 Adam 모멘트와 세대 카운터는 초기화합니다.
  중단 전 상태의 정확한 연속 재개가 아닙니다.
- 검증용 30개 시드는 체크포인트 선택에 반복 사용됩니다. 이 결과를 별도 시험
  집합의 성능으로 제시하면 안 됩니다. 기본 최종 평가 시드 범위는 별도로 설정됩니다.
- 마지막 환경 테스트는 단계 이름 방문과 잔여 연료를 검사합니다.
